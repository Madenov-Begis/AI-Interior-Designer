# Плавающая панель доработки генерации

## Цель

Сделать повторную генерацию контекстным действием над выбранным результатом. Пользователь выбирает изображение, нажимает «Доработать», описывает изменения, при необходимости добавляет референсы или рисует поверх результата и запускает дочернюю генерацию.

## Согласованный сценарий

1. Готовое сгенерированное изображение можно выбрать на холсте.
2. Возле выбранного изображения появляется контекстная панель действий.
3. Кнопка «Доработать» явно открывает плавающий редактор. Простое выделение изображения редактор не открывает.
4. Редактор содержит:
   - поле «Опишите изменения»;
   - счётчик символов;
   - добавление референсов;
   - список уже прикреплённых и новых референсов с удалением;
   - кнопку «Сгенерировать».
5. Формат, стиль, провайдер и модель наследуются от родительской генерации и не показываются в редакторе.
6. Разметка, сделанная поверх результата, автоматически передаётся вместе с текстом и референсами.
7. После отправки редактор закрывается, рядом появляется дочерняя генерация, а родитель остаётся неизменным.

## Компоновка

- Контекстная панель и редактор рендерятся как экранные overlay-элементы поверх viewport, а не внутри масштабируемого содержимого холста.
- Их текст, кнопки и размеры не меняются при zoom холста.
- Панель действий привязывается к видимой границе выбранной карточки и остаётся внутри viewport.
- На широком экране редактор открывается рядом или под панелью действий.
- На узком экране редактор превращается в нижнюю панель, чтобы не перекрывать всё изображение.
- При pan и zoom позиция пересчитывается относительно выбранной карточки.

## Действия

- «Доработать» — открывает или закрывает редактор.
- «Дублировать» — создаёт независимую копию выбранного результата на холсте без запуска AI.
- «Удалить» — удаляет выбранный узел только после подтверждения; серверные данные генерации не удаляются, чтобы не разрушать историю.
- Существующее скачивание результата остаётся доступным в карточке и не дублируется в контекстной панели.

## Состояния

- Редактор доступен только для генерации со статусом `SUCCEEDED` и доступным результатом.
- Черновик текста хранится отдельно для каждой генерации и пользователя.
- Во время отправки поле и кнопки блокируются, показывается состояние «Создаём…».
- Ошибка показывается внутри редактора и не закрывает его.
- `Escape` закрывает редактор без удаления черновика.
- Клик по пустому месту закрывает редактор, но сохраняет черновик.
- После успешной отправки черновик и новые локальные файлы очищаются.

## Компоненты

- `CanvasViewport` вычисляет экранную границу выбранной карточки и передаёт якорь overlay-слою.
- `GenerationCanvasCard` отвечает за изображение, выделение и визуальную разметку, но больше не содержит редактор в своей высоте.
- `GenerationContextActions` отображает контекстные действия выбранного результата.
- `GenerationRefinementPopover` использует существующую логику черновика, референсов и отправки из `GenerationRefinementComposer`.
- `DesignWorkspace` остаётся владельцем выбранной генерации, состояния отправки и создания дочерней генерации.

## Данные

Существующий API дочерней генерации сохраняется. При отправке используются:

- `parentGenerationId`;
- текст нового промпта;
- существующие идентификаторы референсов;
- новые файлы референсов;
- snapshot чистого родительского результата;
- overlay и состояние холста, если пользователь сделал разметку.

## Доступность

- Панель действий имеет семантические кнопки и понятные `aria-label`.
- Редактор получает диалоговую семантику без жёсткой блокировки остального холста.
- При открытии фокус переходит в поле промпта.
- Фокус не теряется при pan/zoom и возвращается на «Доработать» после закрытия.
- Все действия доступны с клавиатуры; видимый focus ring обязателен.
- Disabled-состояние кнопки сохраняет читаемый контраст.

## Проверка

- Unit-тесты позиционирования overlay внутри viewport.
- Component-тесты открытия только по кнопке, закрытия по `Escape`, сохранения черновика и блокировки отправки.
- Проверка, что дочерний запрос не содержит модели, провайдера или новых параметров формата.
- Ручная проверка desktop и mobile: выбор результата, pan, zoom, открытие панели, ввод промпта, референсы, разметка, успешная и ошибочная отправка.
- Регрессионная проверка первой генерации, истории и скачивания JPG.
