## Документы по эксплуатации

Каталог [`launch`](launch/) содержит текущий статус выпуска, чеклисты, мониторинг, резервное копирование, disaster recovery, Google Cloud controls и шаблоны поддержки.

Перед production-действием выбирай конкретный runbook. Не выполняй команды с production credentials только на основании общего описания продукта.

## Юридические документы

Каталог [`legal`](legal/) является source of truth для публичной оферты и политики конфиденциальности. Изменение текста или версии документов требует проверки login flow и записи `LegalAcceptance`.

## История изменений

Завершённые исследования и датированные отчёты не хранятся среди активной документации. При необходимости их можно восстановить из истории Git. Текущее поведение описывается полной документацией продукта, а состояние выпуска — документами в каталоге [`launch`](launch/).

## Правило актуализации

При изменении поведения обновляй в одном наборе изменений:

1. код;
2. тесты;
3. `docs/full-product-documentation.md`;
4. специализированный документ, если изменение затрагивает архитектуру, дизайн, эксплуатацию или юридический текст.

Все новые и изменяемые проектные Markdown-документы пишутся на русском. Имена API, файлов, команд, библиотек и программные идентификаторы сохраняются без перевода.
