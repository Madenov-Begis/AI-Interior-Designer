# Поисковая реклама Ruvie

Актуальность обзора: 19 сентября 2026 года.

## Решение на текущем этапе

Платную рекламу пока не запускать. Production работает как бесплатная beta, реальные платежи отключены, а накопленной статистики по качественным конверсиям ещё нет. До запуска рекламы нужно определить рынки, подключить consent-aware аналитику и измерять не посещение или регистрацию, а завершённую первую генерацию.

## Подходящие рекламные системы

| Система               | Подходящий формат                         | Роль для Ruvie                                                                   |
| --------------------- | ----------------------------------------- | -------------------------------------------------------------------------------- |
| Google Ads            | Search Campaigns, responsive search ads   | Основной будущий канал для глобального англоязычного спроса и локальных кампаний |
| Microsoft Advertising | Search Ads                                | Дополнительный канал для аудитории Bing и Microsoft Search Network               |
| Яндекс Директ         | Текстово-графические объявления на поиске | Отдельный канал для русскоязычных рынков, где есть достаточный поисковый спрос   |

Performance Max, медийную рекламу, видео и ремаркетинг не следует использовать как первый тест: для них нужны корректная аналитика, аудитории и накопленные conversion signals.

## Как формируется цена

У стандартной поисковой рекламы нет фиксированной цены размещения. Google Ads, Microsoft Advertising и Яндекс Директ используют рекламный аукцион. В большинстве поисковых кампаний применяется CPC: рекламодатель платит за клик, а фактическая стоимость зависит от ставки, конкуренции, запроса, страны, устройства, качества объявления и посадочной страницы.

- В Google Ads задаётся средний дневной бюджет. Для большинства кампаний месячный предел рассчитывается как дневной бюджет × 30,4; в отдельный день расход может достигать удвоенного дневного бюджета, не превышая месячный лимит.
- В Microsoft Advertising задаются дневной бюджет и предельная ставка за клик. Фактический CPC зависит от конкуренции и релевантности.
- В Яндекс Директе стоимость клика не фиксирована и определяется аукционом. Специальные медийные размещения на поисковой странице могут использовать CPM, но это не базовый формат для первого performance-теста Ruvie.

Публичная средняя цена клика не даст надёжного бюджета для глобального продукта. Перед запуском нужно получить отдельные прогнозы по каждой стране, языку и группе запросов через Google Keyword Planner, Microsoft Keyword Planner и прогноз бюджета Яндекс Директа.

## Рекомендуемый будущий тест

1. Выбрать одну страну и один язык, а не запускать кампанию сразу по всему миру.
2. Собрать коммерческие запросы, связанные с AI interior design from photo, room redesign и virtual room makeover.
3. Исключить информационные и нерелевантные запросы минус-словами.
4. Вести трафик на соответствующую языковую версию лендинга.
5. Передавать в рекламную систему завершённую первую генерацию как основную конверсию.
6. Установить ограниченный дневной бюджет и оценивать стоимость завершённой генерации, а не только CPC или число регистраций.
