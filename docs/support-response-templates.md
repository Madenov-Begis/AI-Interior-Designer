# Шаблоны поддержки закрытой beta

Перед отправкой заменить поля в квадратных скобках. В GitHub issue, мессенджеры и обычную почту нельзя копировать access token, service role key, полный prompt, приватный signed URL или изображение пользователя. Для поиска операции достаточно request ID, generation ID и примерного времени.

## Ошибка генерации

**Тема:** Ruvie: проверяем ошибку генерации `[GENERATION_ID]`

Здравствуйте, `[ИМЯ]`.

Мы получили обращение по генерации `[GENERATION_ID]` от `[ДАТА И ВРЕМЯ]`. Проверяем технический статус операции. При подтвержденной технической ошибке зарезервированные кредиты возвращаются автоматически; повторную генерацию сервис не запускает без вашего действия.

Пожалуйста, не отправляйте пароль, код входа или ссылку на приватное изображение. Если статус или баланс не обновился после перезагрузки страницы, сообщите request ID из сообщения об ошибке.

Следующее обновление по обращению: `[СРОК]`.

## Запрос на удаление данных

**Тема:** Ruvie: запрос на удаление данных получен

Здравствуйте, `[ИМЯ]`.

Мы зарегистрировали запрос на удаление учетной записи и связанных пользовательских данных под номером `[REQUEST_ID]`. До удаления необходимо подтвердить, что запрос отправлен владельцем аккаунта, и проверить обязательные сроки хранения отдельных финансовых или юридически значимых записей.

После проверки мы сообщим подтвержденный состав удаления и дату завершения. Данные в резервных копиях могут сохраняться до 30 дней и затем перезаписываются по циклу хранения.

Не присылайте пароль, OAuth token или код доступа. Для подтверждения используйте только согласованный канал поддержки.

## Начисление beta-кредитов

**Тема:** Ruvie: решение по beta-кредитам `[REQUEST_ID]`

Здравствуйте, `[ИМЯ]`.

По обращению `[REQUEST_ID]` принято решение `[НАЧИСЛИТЬ / ОТКАЗАТЬ]` `[КОЛИЧЕСТВО]` beta-кредитов по причине: `[КРАТКОЕ ОБОСНОВАНИЕ]`.

Если кредиты начислены, обновленный баланс отображается в профиле и истории операций. Beta-кредиты не являются денежными средствами и не обмениваются на деньги. Технический refund и ручное beta-начисление учитываются как разные операции.

## Внутренняя проверка перед ответом

- пользователь и операция найдены без передачи приватного контента в тикет;
- баланс сверяется с `CreditTransaction`, а не только с числом в интерфейсе;
- manual adjustment содержит понятную причину и уникальный idempotency key;
- удаление не выполняется до проверки личности, активных сессий, Auth, Prisma и Storage;
- срок следующего ответа указан явно.
