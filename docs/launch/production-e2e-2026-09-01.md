## Release и инфраструктура

- Основное приложение и админка собраны Vercel из одного release commit и получили статус `READY`.
- Основная Vercel-сборка завершилась без ошибок за 57 секунд.
- `ruvie.cc`, login и admin отвечают HTTP 200.
- `www.ruvie.cc` отвечает HTTP 308 на `https://ruvie.cc/`.
- Credits API отвечает HTTP 200, возвращает три пакета и `paymentMode=disabled`.
- Auth и admin session endpoints без токена отвечают ожидаемым HTTP 401.
- OAuth dry-run проходит Ruvie `307` → Supabase `302` → `accounts.google.com`.
- Vercel не показал runtime error clusters основного приложения и админки после deploy.

## Что этот прогон не подтверждает

- первоначальную регистрацию нового Google-пользователя и однократное начисление стартовых 10 кредитов;
- logout и новый OAuth-вход после полного удаления сессии;
- JPEG/WebP upload, неподходящие файлы и exterior rejection;
- reference files/URLs и инструменты разметки;
- queued cancellation, technical failure refund, retry и insufficient balance;
- фактическое появление скачанного WebP в папке загрузок;
- responsive Design QA и keyboard/accessibility сценарии (закрыты отдельным
  production-прогоном 2 сентября 2026 года; см. `docs/design/design-qa.md`).

Эти пункты остаются открытыми в `closed-beta-checklist.md`.

- Private/local URL `http://127.0.0.1/test.png` корректно отклонен сообщением
  `Ссылка ведёт во внутреннюю или служебную сеть`.

  а UI показал `Не удалось загрузить ссылку`.
- Ошибка воспроизведена вне UI на Node.js 24 и Undici 8.8.0:
  `ERR_INVALID_IP_ADDRESS: Invalid IP address: undefined`. Причина находится в
  DNS callback `src/server/features/references/safe-fetch.ts`: callback всегда
  возвращает одиночный адрес, хотя Undici вызывает lookup с `options.all=true`
  и ожидает массив адресов.
- После проверки баланс остался 24 кредита, новых генераций не появилось,
  временные референсы удалены, browser console осталась без ошибок.

Результат дополнительного прогона: `BLOCKED` на boundary импорта публичного
URL-референса. Согласно правилу E2E проверка остановлена на первом подтвержденном
сбое; сценарии ниже него не помечались выполненными.
