# Инструкции для пользовательского frontend

Эти правила уточняют корневой `AGENTS.md` для `src/client`.

## Границы

- Соблюдай текущую структуру `entities`, `features`, `shared`, `widgets` и `_pages`.
- Не импортируй `src/server`, `src/generated` или `admin`.
- Работай с backend через существующий HTTP-клиент и публичные DTO.
- Не дублируй серверные secrets, скрытые prompts и проверки доступа на клиенте как источник истины.
- TanStack Query используй для server state; локальный React state — для состояния интерфейса.

## UI

- Переиспользуй компоненты из `src/client/shared/components` и токены дизайн-системы.
- Используй Lucide; не рисуй SVG-иконки вручную без необходимости.
- Для новой страницы или заметного редизайна прочитай `docs/design/design-system.md`.
- Проверяй ширины 375, 768 и 1440 px.
- Сохраняй keyboard navigation, видимый focus и основные touch targets не менее 44 px.
- Асинхронные состояния должны быть понятны визуально и через `aria-live`/`role`, где это уместно.
- Для приватных signed URL не добавляй нестабильную оптимизацию изображений Next.js без отдельного loader.

## Проверка

- Изменение чистой модели: релевантный unit test и `pnpm typecheck`.
- Изменение TSX: релевантный UI-тест, `pnpm test:ui`, `pnpm typecheck` и `pnpm lint` по необходимости.
- Изменение маршрута или сборочной границы: добавь `pnpm build`.
- Визуальное изменение: проверь реальный экран в браузере и отсутствие horizontal overflow.
